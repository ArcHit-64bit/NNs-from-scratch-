#1 NNs from Scratch

So yeah… I got tired of just *using* neural networks without actually understanding what’s going on inside.

This repo is me trying to fix that.

Instead of jumping straight to TensorFlow/PyTorch, I went back to basics and started building everything from scratch , just to see how it actually works.

---

## 2 What’s in here

* A single neuron from scratch
* A layer of neurons
* Handling batch inputs
* ReLU activation
* Softmax (including batch version)

Basically me figuring things out step by step and writing code alongside it.

---

## 3 Why I did this

Most tutorials kinda skip the “why” and go straight to using libraries.

That didn’t sit right with me.

I wanted to:

* actually understand what each number means
* see how data flows through a network
* not feel like it’s all just black magic

So I started rebuilding everything myself.
